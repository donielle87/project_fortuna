    2398(5) Determination of Prize Winners. 2403In order for a ticket to be a winning ticket, numbers appearing in a single horizontal row on the ticket must match the official POWERBALL Winning Numbers in any order for the drawing date for which the ticket was purchased, in one of the following combinations:

    2449(a) Jackpot Prize: Five numbers selected from the first set 2459of balls plus the Powerball number selected from the second set of balls.

    2472(b) Second Prize: Five numbers selected from the first set of balls and not the Powerball number from the second set of balls.

    2495(c) Third Prize: Four numbers selected from the first set of balls plus the Powerball number selected from the second set of balls.

    2518(d) Fourth Prize: Four numbers selected from the first set of balls and not the Powerball number from the second set of balls.

    2541(e) Fifth Prize: Three numbers selected from the 2549first set of balls plus the Powerball number selected from the second set of balls.

    2564(f) Sixth Prize: Three numbers selected from the first set of balls and not the Powerball number from the second set of balls.

    2587(g) Seventh Prize: Two numbers selected from the first set of balls plus the Powerball number selected from the second set of balls.

    2610(h) Eighth Prize: One number selected from the first set of balls plus the Powerball number selected from the second set of balls.

    2633(i) Ninth Prize: No numbers selected from the first set of balls and the Powerball number selected from the second set of balls.

    2656(6) Limited to Highest Prize Won. The holder of a winning ticket may win only one prize per POWERBALL Play in connection with the POWERBALL Winning Numbers drawn and shall be entitled only to the prize won by those numbers in the highest matching prize category. All liabilities for POWERBALL and Power Play prizes are discharged upon payment of a prize claim.
